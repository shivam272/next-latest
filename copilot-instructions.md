# Development Rules

## Code Changes - ASK-ONLY MODE
**NO automatic code changes under any circumstances.** Always ask first.
- Do not modify, create, delete, or rename files unless explicitly asked.
- For any proposed code changes: Show the exact diff, explain the changes, and wait for explicit approval before implementing.
- Never apply edits, even if the change seems obvious or minor.
- Do not modify unrelated files.

## Commands & Dependencies
- Do not execute terminal commands unless explicitly asked.
- Do not start, stop, or restart development servers without permission.
- Do not install, update, or remove dependencies without permission.

## Debugging & Proposals
- For debugging requests, explain the root cause and propose a fix first.
- Show the changes in a diff format before asking permission.
- Wait for explicit "yes" or approval before implementing any changes.
